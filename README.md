# 计算机考研信息墙 📚

面向**计算机方向考研生**的每日信息聚合看板，自动抓取研招网、院校官网、知乎/小红书/CSDN 等信源，汇聚目标院校动态、经验帖、复试攻略与调剂信息，省去逐站翻找的时间。

## 🔗 访问地址

| 入口 | 链接 | 特点 |
|---|---|---|
| **GitHub Pages** | https://fishjoyness.github.io/kaoyan-info-wall/ | 全球可访问，电脑关机也不影响 |
| **CloudStudio** | https://848b34de1ab44e27bc63c5f0de24665c.bj10.agentos-app.net | 云端实时版 |

## 📦 功能模块

- **今日要闻**：24h / 7d 双时间窗切换的考研热门资讯
- **我的目标校**：中山大学、南京大学、上海交通大学动态跟踪
- **院校动态**：985 / 211 院校招生简章、报录比等关键信息
- **经验帖**：知乎高赞 + 小红书 + CSDN 高分经验聚合
- **复试攻略** / **调剂信息**：复试准备要点与调剂机会速览
- **公众号论坛好文**：深度好文精选
- **必备工具**：考研常用网站与工具导航

## ⚙️ 自动刷新机制（双保险）

每天 **09:45（北京时间）** 自动更新：

```
本地 WorkBuddy 自动化        GitHub Actions（cron 45 1 * * * UTC）
    ↓                              ↓
抓取新数据 → 更新页面    从 CloudStudio 拉最新版
    ↓                              ↓
同步到桌面 / E 盘归档     自动 commit + push
    ↓                              ↓
部署 CloudStudio         触发 GitHub Pages 重建
```

即使电脑关机、本地自动化未运行，GitHub 服务器每天也会自动拉取最新数据并更新页面。

## 🛠️ 技术栈

- 纯静态 HTML + CSS + JavaScript，无后端依赖
- GitHub Actions 定时任务驱动数据抓取与更新
- 数据源：研招网、院校研究生院官网、知乎、小红书、CSDN 等
